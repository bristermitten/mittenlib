# MittenLib Documentation

Welcome to the MittenLib documentation. MittenLib is a modern, high-performance configuration and utility library for Java, designed with Guice integration and developer experience in mind.

## Core Features

- **Annotation-Driven Configurations**: Define your config structure in simple DTOs and let the processor handle the rest.
- **Robust Validation**: Built-in and custom constraints to ensure your data is always valid.
- **Guice First**: Native support for dependency injection, allowing for lazy loading and automatic reloads.
- **Type Safety**: Fully typed configurations with support for complex collections and nested types.
