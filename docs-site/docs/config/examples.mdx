# Source vs Generated

MittenLib's annotation processor takes your simple DTO classes and generates robust, type-safe implementation code. 
This page demonstrates actual generated code from a real run of the processor.

## Implementation Generation

The primary output is the implementation class. It is immutable, type-safe, and includes boilerplate like `equals`, `hashCode`, and `toString`.
