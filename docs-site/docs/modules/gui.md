# GUI

The `gui` module provides utilities for creating and managing interactive inventory menus in Bukkit/Spigot.

## Features

While many inventory frameworks exist, MittenLib's GUI module is designed to integrate cleanly with its core Guice ecosystem, allowing you to easily inject services into your menu classes.

*More detailed documentation on the GUI module will be added in the future.*

## Installation

```kotlin
dependencies {
    implementation("me.bristermitten:mittenlib-gui:VERSION")
}
```
